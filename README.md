# negrofarto-web

Vista previa del sitio de Negrofarto Group (negrofarto.com), para que el cliente lo revise y pida cambios.

**Ver:** https://niconania.github.io/negrofarto-web/

| Ruta | Qué es |
|---|---|
| `/` | Portada con los accesos |
| `/temporal/` | Página "Próximamente" (fase 1) |
| `/prototipo/` | Sitio completo: la agencia |
| `/prototipo/merch/` | La Fartedá, tienda con carrito |
| `/prototipo/wuandacrafts/` | WuandaCrafts, pedidos uno a uno |

Es una versión de prueba, no el sitio final:

- Todas las páginas llevan `noindex`.
- Los botones de WhatsApp muestran un aviso de demostración y no envían nada.
- Los textos de servicios, kits y "¿Por qué farto?" están pendientes de validar con Juan.

HTML, CSS y JavaScript simples, sin paso de compilación. Para actualizar la vista previa basta subir los cambios a `main`: GitHub Pages los publica en cerca de un minuto.

El sitio final se publica en Hostinger, en negrofarto.com.
